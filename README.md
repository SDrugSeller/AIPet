# AIPet
overlay pet that connected with AI Agent

> 🤖 **Made with AI** — 이 프로젝트의 설계와 코드는 AI(Claude)의 도움을 받아 작성되었습니다.
> This project was designed and written with the assistance of AI (Claude).

설계 문서: [docs/DESIGN.md](docs/DESIGN.md)

## 실행

```
npm install
npm start        # 실행 (종료: 트레이 또는 펫 우클릭 → 종료)
npm test         # 자동 테스트
npm run lint
```

## 설치 파일 만들기 (Windows)

```
npm run pack     # dist/win-unpacked/ (설치 없이 실행해 볼 때)
npm run dist     # dist/AIPet-Setup-<버전>.exe (NSIS 설치 파일)
```

- 설치본에는 `src/`, `personas/`, `skins/default`만 들어가며 개인용 스킨(`skins/genba-cat`)은 제외됩니다.
- 코드 서명이 없어서 다른 PC에서 SmartScreen 경고가 뜰 수 있습니다. 앱 아이콘은 임시입니다(`build/icon.png`).
- 셸에 `ELECTRON_RUN_AS_NODE=1`이 설정돼 있으면(VS Code 터미널 등) `npm start`와 빌드가 실패하므로 해제하고 실행하세요.

- 펫을 **클릭**하면 말풍선 입력창이 열리고, **드래그**하면 옮길 수 있습니다.
- **트레이 아이콘**: 왼쪽 클릭은 펫 숨기기/보이기, 오른쪽 클릭은 메뉴(연결별 켜기/끄기, 설정, 종료). 펫을 우클릭해도 같은 메뉴가 나옵니다.
- **연결 = 캐릭터**: AI 계정/서버 하나를 "연결"로 등록하면 연결마다 펫이 한 마리씩 화면에 뜹니다(최대 8). 연결마다 **스킨·말투·계정/키가 따로**이고, 대화창도 펫마다 따로 여러 개를 동시에 열 수 있습니다. 설정에서 추가/삭제/켜기·끄기 하면 바로 반영됩니다.
- **설정**(메뉴 → 설정…, 탭: 연결 / 말투 / 펫 / 알림 / 일반): 연결 목록(종류, 이름, 스킨, 말투, 경로/주소/모델/API 키, 도구 사용), 작업 폴더, 알림음, 로그인 시 자동 시작. 값은 바꾸는 즉시 저장되고 재시작해도 유지됩니다 (`%APPDATA%/aipet/settings.json`). 예전 형식의 설정은 자동으로 변환됩니다.
- 연결 종류 (같은 종류를 여러 개 만들 수 있습니다):
  - **Claude Code**: 공식 `claude` CLI를 설치하고 터미널에서 한 번 로그인해 두면 자동으로 감지합니다. (설정에서 지정한 경로 → PATH → 공식 설치 위치 → VS Code Claude Code 확장에 포함된 바이너리 순으로 탐색) 어떤 계정인지 설정 화면에 표시됩니다. **계정을 여러 개** 쓰려면 연결마다 "계정 설정 폴더"를 다르게 지정하세요(`CLAUDE_CONFIG_DIR`로 전달됨). "자동 지정"으로 폴더를 만들고, "로그인 명령 복사"로 받은 명령을 터미널에 붙여 그 계정으로 로그인하면 됩니다. 파일/명령 도구와 권한 승인 카드를 지원하는 유일한 종류입니다.
  - **Codex CLI**, **Gemini CLI**: 각 공식 CLI를 설치·로그인해 두면 쓸 수 있습니다. **읽기 전용**(Codex `-s read-only`, Gemini `--approval-mode plan`)이라 파일을 고치거나 명령을 실행하지 않습니다. 대화 기록은 앱이 매번 프롬프트에 이어 붙입니다.
  - **Anthropic API**: 공식 SDK(`@anthropic-ai/sdk`)로 스트리밍 대화. API 키 + 모델(기본 `claude-opus-5-5`)을 입력합니다. 대화 전용.
  - **Ollama / OpenAI 호환**: 기본 주소 `http://127.0.0.1:11434/v1`. 모델을 지정하지 않으면 서버의 첫 모델을 씁니다. 대화 전용.
  - API 키는 연결마다 OS 보안 저장소(Electron `safeStorage`)에 암호화해 저장하며, 보안 저장소를 쓸 수 없으면 저장하지 않습니다.
- **권한**(Claude Code 연결의 도구 사용):
  - 에이전트는 설정한 **작업 폴더** 안에서만 일합니다 (기본: 앱 전용 폴더). 폴더 밖 경로는 묻지 않고 거부합니다.
  - 읽기 전용 도구(Read/Glob/Grep 등)는 자동 허용(설정에서 끌 수 있음). 파일 쓰기, 명령 실행, 네트워크는 **말풍선의 승인 카드**에서 허용/거부합니다.
  - 승인 요청이 오면 펫이 놀란 표정을 짓고 알림음이 납니다. 다른 앱을 쓰는 중이어도 포커스를 가져가지 않습니다.
- 환경변수(연결에 값이 없을 때의 기본값): `AIPET_CLAUDE_PATH`, `AIPET_OPENAI_BASE_URL`, `AIPET_OPENAI_MODEL`, `AIPET_OPENAI_KEY`, `ANTHROPIC_API_KEY`
- 디버그(`AIPET_DEBUG=1`): 히트박스 표시, 로그 출력. `AIPET_START_DISPLAY`, `AIPET_SLEEP_AFTER_SEC`, `AIPET_AUTOTEST_MSG`, `AIPET_OPEN_SETTINGS`, `AIPET_CAPTURE_DIR`, `AIPET_FAKE_WINDOW="x,y,w,h"`(가짜 활성 창으로 올라가기 검증), `AIPET_TEST_NOTICE="문구"`(알림 말풍선), `AIPET_NOTIFY_TICK_MS`, `AIPET_SKIN`(모든 연결에 한 스킨을 강제)
- 임시 스프라이트는 `node tools/gen-placeholder-skin.mjs`로 다시 만들 수 있습니다.

## 행동과 먼저 말 걸기

- **창 위에 올라가기**(Windows): 활성 창이 올라갈 만하면 펫이 창 아래까지 걸어가 뛰어올라 윗변에 서고, 창을 끌면 같이 움직이며, 다른 창으로 전환하거나 창을 닫으면 내려옵니다. 최대화/최소화/전체화면 창, 머리가 화면 위로 나가는 높이의 창, 몸이 들어가지 않는 좁은 창은 제외합니다. 지금은 **걸터앉은 전용 그림이 없어서** 서 있는 자세로 올라섭니다.
- **개인정보**: 활성 창의 **위치/크기/프로세스 이름**만 읽습니다. 창 제목과 내용은 읽지 않고, 값은 이 PC 밖으로 나가지 않습니다. (읽는 방법: 앱이 띄우는 상주 PowerShell이 Win32 API를 0.1초마다 확인) 설정에서 끌 수 있습니다.
- **전체화면 앱(영상·게임·발표)**이 활성이면 펫을 숨기고 먼저 말을 걸지 않습니다.
- **먼저 말 걸기**는 설정에서 통째로 끌 수 있습니다("먼저 말 걸기 사용"). 정해진 문구나 이미 받은 답을 보여 줄 뿐 **AI를 호출하지 않아서 토큰을 쓰지 않습니다.** 기본적으로 조용합니다. 방해 금지(트레이/우클릭 메뉴 또는 설정), 전체화면, 대화 중, 숨김 상태에서는 말하지 않고, 쿨다운(기본 30분)을 지킵니다.
  - 대화창을 닫아 둔 사이 답이 오면 말풍선으로 알림 (기본 켜짐)
  - 오래 쉬지 않고 컴퓨터를 쓰면 쉬라는 말 (기본 꺼짐, 입력이 5분 이상 없으면 쉰 것으로 봄)
  - 정해진 시각 알림 (설정에서 추가). 조용해야 해서 못 전하면 30분 안에 전합니다.

## 스킨 크기 조정

설정 창의 "스킨 크기"에서 **프레임 크기(px)**와 **화면에 표시할 높이(px)**를 입력하면, 크기·발 위치(앵커)·클릭 영역(히트박스)이 자동으로 환산됩니다. 기준은 `skin.json`에 적힌 원본 값이고, 시트를 다른 해상도로 바꿨을 때 실제 프레임 크기를 입력하면 앵커/히트박스가 그 비율만큼 늘고 줄어듭니다. 표시 높이를 그대로 두면 해상도를 바꿔도 화면에서 보이는 크기는 같습니다. "시트에서 자동 감지"는 PNG 크기에서 프레임 크기를 읽어 주고, 시트 크기가 프레임 수와 맞지 않으면 경고합니다. 스킨별로 저장되며 적용하면 앱이 다시 시작됩니다.

## 말투

- 펫의 말투/성격은 **텍스트 파일 하나 = 말투 하나**로 `%APPDATA%/aipet/personas/`(설정 창에 경로 표시)에 저장됩니다. 처음 실행하면 저장소의 [personas/](personas/) 폴더(기본, 친구 (반말), 비서 (존댓말), 현장냥이, 한 줄 요약)를 복사해 채웁니다.
- 말투 파일의 수정/새로 만들기/삭제는 설정 창의 "말투" 탭에서, **어떤 연결이 어떤 말투를 쓸지**는 각 연결 카드(또는 펫 우클릭 메뉴)에서 고릅니다. 파일을 직접 편집하거나 `.txt`를 폴더에 넣어도 목록에 나타납니다.
- 시스템 프롬프트 = 말투 파일 내용 + 앱이 붙이는 도구 사용 안내(도구 가능/불가, 승인 규칙). 다음 메시지부터 적용되며, Claude Code는 말투를 바꾸면 새 대화로 시작합니다 (CLI가 처음 보낸 프롬프트를 세션에 기록하기 때문).

## 스킨

- `skins/<이름>/skin.json` + 상태별 PNG 시트. 각 연결 카드의 "스킨"에서 고릅니다. 형식은 [skins/skin.schema.json](skins/skin.schema.json).
- `default`: 임시 콩 캐릭터 (`node tools/gen-placeholder-skin.mjs`로 생성).
- **스킨 추가하기** (설치본에서도 가능): 설정 → 펫 → "스킨 추가"의 **스킨 폴더 열기**를 누르면 사용자 스킨 폴더(`%APPDATA%/AIPet/skins`)가 열립니다. 거기에 스킨 폴더를 통째로 넣고 **목록 새로고침**을 누르면 각 연결 카드의 스킨 목록에 "· 내가 추가"로 나타납니다.
  - 만드는 법: 저장소의 `skins/default` 폴더를 복사해 이름을 바꾸고, `skin.json`의 `name`/`author`와 PNG 시트를 바꿉니다. 시트는 가로 1줄이고 너비 = 프레임 너비 × `frames`입니다 (스키마: [skins/skin.schema.json](skins/skin.schema.json), 규격: [docs/DESIGN.md](docs/DESIGN.md) 5.4). `idle`만 필수입니다.
  - 폴더 이름은 영문, 숫자, `-`, `_`만 쓸 수 있고(한글·공백 불가), 앱 내장 스킨과 이름이 같으면 내장 쪽이 우선합니다.
  - 스킨은 `skin.json`과 PNG만 읽으며 코드는 실행되지 않습니다. 외부에서 받은 스킨은 값의 범위(프레임 크기, 프레임 수, fps, 시트 경로)를 검사하고, 맞지 않으면 목록에 나타나지 않습니다. 이미 쓰는 스킨을 고쳤다면 앱을 다시 시작해야 반영됩니다.
  - 받은 스킨의 그림은 만든 사람에게 권리가 있습니다. 출처와 이용 조건을 확인하고 쓰세요.
- `genba-cat`: **개인용이며 저장소에 포함되지 않습니다**(`.gitignore`, 커밋 기록에서도 제거). 직접 쓰려면 `skins/genba-cat/source.webp`에 원본 이미지를 두고 `tools/genba`로 만듭니다. 패키징/배포 때도 제외해야 합니다. 웹의 밈 캐릭터 "현장냥이(現場猫)" 이미지 **한 장**(`skins/genba-cat/source.webp`)에서 만든 스킨입니다.

### 애니메이션 속도(fps) 참고표

기본 스킨(`skins/default/skin.json`)의 값입니다. 스킨을 만들 때 기준으로 삼으세요. 속도는 설정 창에서 바꿀 수 없고 `skin.json`의 `fps`/`frames`로만 정합니다.

| 상태 | fps | 프레임 수 | 한 바퀴 | 반복 |
|---|---|---|---|---|
| idle (대기) | 6 | 6 | 1.00초 | 반복 |
| walk (걷기) | 10 | 8 | 0.80초 | 반복 (`moveSpeed` 60px/초) |
| drag (집힘) | 6 | 3 | 0.50초 | 반복 |
| drop (착지) | 10 | 4 | 0.40초 | 한 번 → idle |
| sleep (잠) | 3 | 4 | 1.33초 | 반복 |
| think (생각 중) | 6 | 6 | 1.00초 | 반복 |
| work (작업 중) | 10 | 8 | 0.80초 | 반복 |
| talk (답하는 중) | 8 | 4 | 0.50초 | 반복 |
| done (완료) | 10 | 8 | 0.80초 | 한 번 → idle |
| attention (허가 필요) | 8 | 6 | 0.75초 | 반복 |
| error (오류) | 8 | 6 | 0.75초 | 한 번 → idle |
| react (클릭 반응) | 10 | 5 | 0.50초 | 한 번 → idle |
| yawn (하품, 랜덤) | 8 | 6 | 0.75초 | 한 번 → idle |
| look_around (두리번, 랜덤) | 6 | 6 | 1.00초 | 한 번 → idle |

- 움직임이 큰 동작(걷기, 작업, 완료, 착지, 클릭 반응)은 **10fps**, 보통 동작은 **6~8fps**, 잠은 **3fps**입니다. 한 바퀴 시간은 `프레임 수 ÷ fps`입니다.
- 허용 범위는 fps 0.1~60, 프레임 수 1~64입니다 (사용자가 추가한 스킨 기준). 시트는 가로 1줄이고 너비 = 프레임 너비 × 프레임 수입니다.
- fps만 올리면 같은 그림이 더 빨리 반복될 뿐이라, 더 부드럽게 하려면 프레임 수도 늘려 그림을 다시 만들어야 합니다.
  - 배경을 지우고, 몸을 격자 메시로 덮어 관절(머리, 팔, 다리, 꼬리, 입, 눈)만 휘게 해서 idle/walk/drag/drop/sleep/think/work/talk/done/error/attention 시트를 만듭니다. 새 포즈를 그린 것이 아니라 한 장을 변형한 것이라 움직임은 단순합니다.
  - 완료(done) 모션에서는 원본에 있던 "ヨシ!" 글자를 외칩니다.
  - 다시 만들려면 `npx electron tools/genba/build.cjs` (움직임 조정은 `tools/genba/page.js`). 더 나은 시트(직접 그리거나 생성한 그림)가 생기면 같은 파일명의 PNG로 교체하면 됩니다.
  - **저작권**: 원본 이미지의 권리는 원작자에게 있습니다. 개인 사용을 전제로 했으며, 재배포 전에 확인이 필요합니다 (`skin.json`의 `license` 참고).
