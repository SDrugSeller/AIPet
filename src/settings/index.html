AI 연결

펫이 어떤 AI와 이야기할지 고르세요. 앱은 로그인 정보를 직접 받거나 저장하지 않아요. Claude Code는 터미널에서 직접 로그인한 계정을, 다른 연결은 아래에 입력한 주소/키를 사용해요. 


          

          
          
          
        


        

          

            
            
          

          

          

          
          
          
          
API 키 (선택, OS 보안 저장소에 암호화해 저장돼요)
            

              
              
              
            

            
          

          
이 연결은 대화만 가능해요 (파일·명령 도구 없음).

        


        
      


      

        
말투

        
펫이 어떤 말투와 성격으로 대답할지 정하는 프롬프트예요. 말투 하나가 텍스트 파일 하나이고, 아래 폴더에 저장돼요.

        
        
        

          
          
        

        
새 말투 만들기 (위 프롬프트 내용을 복사해 새 파일로 저장해요)
          

            
            
          

        

        

        
다음 메시지부터 적용돼요. Claude Code는 말투를 바꾸면 새 대화로 시작해서 이전 대화 내용은 기억하지 못해요.

      


      

        
권한

        
        
작업 폴더 (펫이 파일을 읽고 쓸 수 있는 범위)
          

            
            
            
          

        

        
파일 쓰기, 명령 실행, 네트워크 접근은 항상 말풍선으로 허용 여부를 물어요. 작업 폴더 밖의 경로는 거부돼요.

      


      

        
행동

        
        
      


      

        
먼저 말 걸기

        

          펫이 부르지 않았는데 말풍선으로 알려 주는 기능이에요. 정해진 문구나 이미 받은 답을 보여 줄 뿐,
          AI를 호출하지 않아서 토큰을 쓰지 않아요.
          방해 금지일 때, 전체화면 앱이나 발표 중일 때, 대화 중일 때는 말하지 않아요.
        

        
        

        
        
        
        
        
        
        
정해진 시각 알림
          

          
        

        

      


      

        
일반

        
        
        
      


      

        
스킨 크기

        

          시트(PNG)의 한 칸(프레임)이 몇 픽셀인지와, 화면에서 펫이 몇 픽셀 높이로 보일지를 정해요.
          이 값에 맞춰 크기, 발 위치(앵커), 클릭 영역(히트박스)이 자동으로 조절돼요.
          다른 해상도의 그림으로 바꿨을 때 써 보세요.
